# Limitations

1. The pilot has 12 synthetic tasks, below the 60-task minimum for an initial effectiveness conclusion.
2. There are no minimized real-world defects yet.
3. Static rules are intentionally small and may be overfit to the control taxonomy.
4. Hidden tests are authored by the same research process as the tasks.
5. The runtime is a managed Linux container without Docker, external DNS, or cross-platform execution.
6. GitHub CI, tag, Release, and release assets are not yet externally verified.
7. There is no independent second adjudicator.
