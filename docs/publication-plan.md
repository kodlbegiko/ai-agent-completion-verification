# Publication Plan

1. Create and authorize the dedicated GitHub repository.
2. Publish the protocol on a branch and merge through PR.
3. Create `protocol-v0.1.0` only after confirming the public commit.
4. Run CI and reproducibility jobs.
5. Publish `v0.1.0-pilot` only if the 12-task minimum, CI, reproducibility, integrity, and limitation-disclosure gates pass.
6. Do not publish an initial-results release until at least 60 valid tasks and real-world evidence are available.
